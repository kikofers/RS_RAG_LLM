What is a code ticket?
* A code ticket allows you to pay for trips on Riga's public transport using a smartphone online. The code ticket works in parallel with the existing e-ticket system. To use a code ticket, customers must install a mobile app on their smartphone. The app can be downloaded:

You can purchase time and day tickets, as well as monthly tickets, for which a fare discount is not applicable, in the Mobilly app.
When boarding public transport, you must scan the code or enter the transport identification number, which is visible under the square code.

What is an identification number?
* Each tram, trolleybus and bus has a unique identification number consisting of five digits. The identification numbers are visible both under the square code and are located inside and outside the vehicle.

What to do if you cannot buy a ticket in the app?
* If there are sufficient funds in the bank account, but the purchase fails, we encourage you to inform “Rīgas satiksme” about this case and choose other payment methods for using public transport.

What to do if a ticket inspector boards a public transport vehicle?
* In the event that a ticket inspector boards the transport, you must open the app and show the registered ticket to the inspector.

If the registered ticket cannot be presented at the time of ticket inspection, for example, the smartphone stops working during the journey (discharged, broken screen or other malfunctions), the ticket inspector will apply a penalty for driving without a ticket, but the customer has the right to submit an application to “Rīgas satiksme” for a review of the justification for applying the penalty, indicating:
* the customer identification code (available in the mobile app) and/or mobile phone number;
* information about the penalty (for example, by attaching a copy of the penalty receipt);
* information that justifies the purchase of the ticket (for example, indicating the date of purchase or attaching an invoice), and information about the ticket authorization – date, time and vehicle identification number (available in the mobile application).

How to get a refund for unused code tickets?
* We encourage you not to purchase unnecessary tickets. If you have purchased code tickets, but cannot use them within 3 months from the date of purchase, you must go to one of the customer service centers and submit an application for a refund, indicating the customer identification code and/or mobile phone number in the application, as well as the bank account number if you want to receive a refund by transfer. Payment for tickets can be received in the amount of 90% of the specified amount.
